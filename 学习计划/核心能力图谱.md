# 核心能力图谱：拥抱 AI 的终端开发工程师

> 对标层级：阿里 P6–P7 / 字节 2-2～2-3
> 制定日期：2026-08-03
> 定位：以 iOS 终端开发为主战场，兼具 AI 工程落地能力的复合型工程师

---

## 层级能力画像（先搞清楚"考什么"）

**P6 / 2-2（高级工程师）**：能独立负责中大型模块的设计与交付。面试考察重心在"基础扎实 + 执行力强"——语言细节问得深（Swift/OC 原理）、算法手写必须过关、对自己做过的项目能讲清技术选型与踩坑。性能优化有实战经验（至少完整做过启动/卡顿/内存中的一项）。

**P7 / 2-3（技术专家）**：能负责一个子系统或技术方向，具备架构设计、技术判断与影响力。面试考察重心在"体系化 + 深度 + 前瞻性"——不仅会用，还要能从第一性原理解释为什么；能设计一套监控/架构/工具链并推动落地；对新技术方向（当下即 AI）有自己的判断和实践。

**2026 年的增量要求**：终端 + AI 已是标配考察项。P6 要求"会用 AI 工具提效 + 能在 App 中集成 AI 能力"；P7 要求"能设计端侧 AI 架构、理解 LLM/Agent 工程化、有 AI 产品技术落地经验"。

## 能力一：编程语言深度（Swift / Objective-C）

> 面试出现率 100%。P6 要求语言特性"知其所以然"，P7 要求能站在语言设计层面做判断（如推动 Swift 迁移、设计 DSL）。

### Swift 语言核心

- 类型系统：值类型 vs 引用类型、struct/class/enum 选型、枚举与关联值、模式匹配
- 协议与泛型：协议（关联类型、Self 约束）、协议扩展、条件一致性、泛型约束、类型擦除（AnyBox/Eraser）
- 闭包：捕获语义、逃逸闭包、@autoclosure、内存影响
- 内存语义：ARC 在 Swift 中的行为、Copy-on-Write、Ownership（~Copyable、consuming/borrowing）
- 高级特性：属性包装器（@propertyWrapper）、Result Builder、KeyPath、动态成员查找、宏（Macro）
- 并发：async/await、Actor、Sendable、结构化并发（TaskGroup/async let）、分布式 Actor（了解）
- 错误处理：throws/try/catch、Result 类型、typed throws
- some/any 存在类型、不透明类型
- Swift 与 C/C++ 互操作、Swift 编译流程（SIL）

### Objective-C 核心

- Runtime 数据结构：isa/class/method/protocol 结构体、Method IMP SEL
- 消息发送与转发：objc_msgSend 流程、快速查找 → 慢速查找 → 消息转发三阶段
- Category 与 Associated Object：实现原理、与 Extension 区别
- Block：三种 Block、__block 捕获、循环引用与 __weak/__block 配合
- KVO/KVC：isa-swizzling 实现原理、手动触发、容器类 KVO
- Property：attribute 语义（atomic/copy/strong/nonatomic）、setter 生成
- Method Swizzling：实践场景与风险
- OC 与 Swift 混编：桥接头文件、NS_SWIFT_NAME、CF 类型桥接

## 能力二：计算机基础

> 大厂面试硬门槛。算法是笔试/手撕环节，网络与操作系统是八股 + 场景题来源，设计模式在架构面中考察。

### 数据结构与算法

- 基础数据结构：数组、链表、栈、队列、哈希表（冲突解决）、二叉树（BST/AVL/红黑树概念）、堆、图（邻接表/矩阵）、Trie
- 排序与查找：快排/归并/堆排（手写）、二分查找及变体
- 算法思想：双指针（对撞/快慢）、滑动窗口、BFS/DFS、回溯、贪心、分治
- 动态规划：状态定义与转移、背包问题、区间 DP、树形 DP、状态压缩（了解）
- 图论：最短路（Dijkstra/Floyd）、拓扑排序、并查集
- 复杂度分析：时间/空间、均摊分析、最优解思维
- 实战能力：LeetCode Hot 100 级别 30 分钟内 bug-free 写出

### 计算机网络

- 网络模型：OSI 七层 / TCP/IP 四层，各层职责
- TCP：三次握手/四次挥手、滑动窗口、拥塞控制（慢启动/快重传）、TIME_WAIT、粘包
- UDP：特点与适用场景（直播/DNS/QUIC 底层）
- HTTP：HTTP/1.1 管线化问题、HTTPS 握手（TLS 1.2/1.3）、HTTP/2 多路复用与头部压缩、HTTP/3 与 QUIC
- DNS：解析流程、HTTPDNS、DNS 劫持与防护
- 安全：对称/非对称加密、证书链、证书锁定（Certificate Pinning）、中间人攻击
- 终端网络实践：弱网优化策略（超时/重试/降级/预连接）、长连接与心跳、网络库设计（URLSession 底层、CFNetwork）
- WebSocket / SSE（Server-Sent Events，AI 流式输出场景）

### 操作系统

- 进程与线程：区别、iOS 中的 Mach 线程、协程概念
- 内存管理：虚拟内存、分页/分段、mmap、malloc 实现（iOS 的 libmalloc zone）、内存映射与 dirty/clean page
- 同步与锁：互斥锁/读写锁/自旋锁/信号量、iOS 中的 os_unfair_lock/pthread_mutex/dispatch_semaphore、死锁条件与预防
- I/O：阻塞/非阻塞、select/poll/kqueue（iOS）、零拷贝概念
- 调度：iOS 优先级与 QoS、GCD 队列与线程池关系
- 文件系统：APFS 基础、沙盒、文件读写性能

### 设计模式与架构思维

- 创建型：单例（Swift 中的正确写法）、工厂、抽象工厂、Builder
- 结构型：适配器、装饰器、代理（Proxy）、外观（Facade）、组合
- 行为型：观察者（Delegate/KVO/NotificationCenter）、策略、责任链、命令、迭代器、状态
- iOS 中的模式实践：Delegate 模式为何在 Apple 生态流行、Target-Action、响应链即责任链
- 架构原则：SOLID、DRY/KISS/YAGNI、关注点分离、依赖倒置

## 能力三：iOS 专业技术

> 日常工作的核心能力面。P6 要求各项都能独立完成，P7 要求在其中 1-2 项有深入体系化建设。

### UI 与渲染

- UIKit：视图生命周期、事件响应链与手势冲突、Auto Layout 约束求解与性能
- Core Animation：CALayer 属性与隐式动画、渲染管线（CPU/GPU 协作）、CADisplayLink
- 离屏渲染：触发条件、检测与规避
- 卡顿优化：主线程耗时操作治理、异步绘制（AsyncDisplayKit 思想）、列表性能（预排版/复用/预加载）
- SwiftUI：声明式 UI 思想、状态管理（@State/@Binding/@Observable/@Environment）、数据流架构、NavigationStack、与 UIKit 混编策略
- 动态化：热更新方案原理（JSPatch 思路与合规风险）、动态布局方案

### 并发编程

- GCD：队列/组/信号量/栅栏、dispatch_once 原理、线程安全单例
- RunLoop：数据结构、运行流程、与主线程事件循环的关系、应用（卡顿检测、任务调度）
- Operation：依赖关系、取消、自定义并发 Operation
- Swift Concurrency：async/await 底层（协程/Continuation）、Actor 隔离、结构化并发、Task 取消与优先级
- 线程安全实践：数据竞争检测（TSan）、Sendable 协议、@MainActor 使用

### 存储与数据

- 持久化方案选型：UserDefaults/文件/SQLite(FMDB/GRDB)/Core Data
- 缓存设计：NSCache、LRU/LFU 策略、多级缓存（内存-磁盘）
- 数据库性能：索引、WAL 模式、线程安全
- 数据同步：离线优先、冲突解决策略（了解）

### 多媒体与设备能力（按需深入）

- AVFoundation：播放/录制管线、AudioSession
- 相机/传感器/定位/蓝牙（按业务方向）
- Widget/App Intents/Live Activity 等系统能力集成

## 能力四：底层原理与性能优化

> P7 分水岭。面试中"你做过什么性能优化"是必问题，且会追问到原理层。要求不仅会"治"，还要能建立"防"的体系（监控 + 归因 + 防劣化）。

### 编译、链接与二进制

- 编译流程：Clang 前端（OC→IR）→ LLVM 优化 → 机器码；Swift 编译（SIL → IR）
- Mach-O 格式：Header/Load Commands/Segment/Section、__TEXT/__DATA
- 链接：静态库(.a)/动态库(.dylib/.framework)、符号解析与绑定（bind/lazy bind）
- dyld：加载流程（load → rebase → bind → ObjC setup → initializers）
- 包大小优化：资源压缩、dead code stripping、Link Map 分析

### App 启动优化

- 冷启动全阶段：dyld → runtime → main() → 首帧渲染
- pre-main 优化：减少动态库、合并 Category、+load 治理、二进制重排（Clang SanitizerCoverage 采集 + Page Order）
- main 后优化：任务分级调度、延迟加载、预加载策略
- 度量体系：启动耗时线上监控、分位数统计、劣化防控

### 卡顿与渲染优化

- 帧率与渲染管线：一帧 16.67ms 的预算分配
- 卡顿检测方案：RunLoop 超时检测、子线程 ping 主线程、CADisplayLink 帧率统计
- Instruments：Time Profiler、System Trace、Animation Hitches
- 优化手段：主线程减负、预计算/预排版、异步渲染、降帧策略

### 内存优化

- iOS 内存模型：虚拟内存、Jetsam 机制、内存水位线（memoryWarning）
- OOM 归因：FOOM/BOOM 区分、大对象追踪、内存快照对比（Memory Graph）
- 优化手段：AutoreleasePool、图片内存（解码/降采样/位深）、缓存上限、循环引用治理
- 监控体系：线上内存水位采集、OOM 率归因方案

### 稳定性建设

- Crash 收集原理：Mach 异常 → Unix 信号 → NSException，KSCrash 架构
- 符号化：dSYM、离线/在线符号化流程
- 死锁/Watchdog/ANR 检测
- APM 体系：指标采集 → 聚合 → 归因 → 报警 → 防劣化

### 电量与包大小

- 耗电归因：CPU 唤醒、GPS/蓝牙/网络后台活动、Energy Organizer
- 包大小治理：资源审计、代码裁剪、App Thinning/On-Demand Resources

## 能力五：架构设计与工程化

> P7 核心考察项。面试中以"系统设计"形式出现：给你一个场景，设计一个组件/框架/整体方案。

### App 架构模式

- MVC：Apple 式 MVC 的问题与 Massive ViewController
- MVVM：ViewModel 职责、数据绑定（Combine/闭包/@Observable）
- VIPER：Clean Architecture 在 iOS 的映射、适用场景
- TCA（The Composable Architecture）：单向数据流、Reducer/Effect/State
- 架构选型判断力：不同团队规模/业务复杂度下的取舍

### 组件化与模块化

- 组件化方案：CocoaPods 私有库、Framework、SPM
- 模块间通信：URL Router、Protocol 面向接口、Target-Action
- 依赖管理：依赖方向控制、循环依赖治理、依赖注入（DI）
- 大型 App 工程实践：多 Target/多 Scheme、编译加速（xcbuild/分布式编译）

### 工程化与质量

- CI/CD：Xcode Cloud/Fastlane/自建流水线、自动化测试与分发
- 测试：单元测试（XCTest/Swift Testing）、UI 测试、快照测试、TDD 实践
- 代码质量：SwiftLint、Code Review 机制、静态分析
- 版本管理与发布：Git Flow、AB 实验、灰度发布、热修复（合规范围内）

### 终端系统设计能力（P7 面试高频）

- 设计一个图片库（加载/缓存/解码/降采样）
- 设计一个网络层（请求抽象/拦截器/重试/弱网策略）
- 设计一个路由框架 / 组件化方案
- 设计一个 APM/监控系统（采集/上报/聚合/报警）
- 设计一个 AI 对话模块（流式渲染/上下文管理/降级策略）
- 跨端技术理解：Flutter（Skia 渲染）、React Native（Bridge/Fabric）、KMP 的架构与适用边界

## 能力六：AI 基础与大模型原理

> 2026 年 P6-P7 的新增必修项。不要求你训模型，但必须理解原理到"能和算法同学对话、能做正确技术选型"的程度。

### 数学与机器学习基础

- 线性代数：向量/矩阵运算、点积的几何意义、特征值（理解即可）
- 概率与统计：条件概率、贝叶斯、分布、期望/方差
- 微积分直觉：梯度、链式法则、损失曲面
- ML 基础概念：监督/无监督/强化学习、过拟合/正则化、交叉验证、评估指标（Precision/Recall/F1/AUC）
- 经典模型（了解思想）：线性回归、逻辑回归、决策树、SVM、K-Means

### 深度学习

- 神经网络：感知机 → 多层网络、激活函数（ReLU/GELU/Sigmoid）
- 训练流程：前向传播、损失函数、反向传播、梯度下降（SGD/Adam）
- 经典架构演进：CNN → RNN/LSTM → Attention（理解为什么被 Transformer 取代）
- 正则化与训练技巧：Dropout、BatchNorm/LayerNorm、学习率调度
- PyTorch 基础：Tensor、autograd、训练循环（能读懂和跑通代码即可）

### Transformer 与大语言模型

- Self-Attention：Q/K/V 的含义、注意力分数计算、为什么除以 √d_k
- Multi-Head Attention：多子空间并行的直觉
- 位置编码：正弦编码 → RoPE
- GPT 架构：Decoder-Only、因果 Mask、自回归生成
- Tokenizer：BPE 分词、词表大小对多语言/代码的影响
- 预训练与 Scaling Law：数据/参数/算力的关系、涌现能力
- 推理过程：Prefill 与 Decode、KV Cache、采样策略（Temperature/Top-p/Top-k）

### 微调与对齐

- SFT（监督微调）：指令数据格式、微调策略
- PEFT：LoRA/QLoRA 原理与适用场景
- RLHF/DPO：对齐的目标与流程（理解思想）
- 模型评估：Benchmark（MMLU/HumanEval/GSM8K）、人工评估
- 模型选型判断：开源 vs 闭源、参数量 vs 推理成本、端侧 vs 云端

## 能力七：AI 应用工程（Agent / RAG / 端侧 AI）

> 这是"终端 + AI"复合型人才的核心差异化竞争力，也是 P7 技术前瞻性的最佳证明。

### LLM 应用开发基础

- API 调用：OpenAI/Anthropic/国内模型 API、流式输出（SSE）、Token 计费
- Prompt Engineering：角色设定、Few-shot、CoT、结构化输出（JSON Mode/Function Calling）
- 上下文工程：上下文窗口管理、对话历史压缩、System Prompt 设计
- 结构化输出与可靠性：JSON Schema 约束、重试与校验

### RAG（检索增强生成）

- 流程全景：文档加载 → 切片 → Embedding → 入库 → 检索 → 重排 → 生成 → 评测
- Embedding：语义向量、模型选型（text-embedding 系列）
- 向量数据库：FAISS/Chroma/Milvus、索引类型（IVF/HNSW）、相似度计算
- 检索策略：混合检索（向量+关键词）、Chunk 策略、Query 改写
- 重排与评测：Reranker、RAGAS 评测框架、Bad Case 分析

### Agent 架构

- ReAct：推理与行动交替的范式
- Tool Use / Function Calling：工具定义、调用协议、错误处理
- Planning：任务分解、CoT/ToT、Reflection
- Memory：短期记忆（上下文）、长期记忆（向量存储/摘要）
- 多 Agent 协作：角色分配、通信模式、适用场景与局限
- 主流框架：LangChain/LangGraph、AutoGen、CrewAI、OpenAI Agents SDK

### Harness 与工程落地

- Agent Harness：运行时框架、工具沙箱、权限控制
- 评测体系（Eval）：任务设计、自动评估、A/B 对比、回归测试
- 可观测性：Trace/Log/指标、调用链追踪
- 成本与安全：Token 成本控制、Prompt 注入防护、输出审核（Guardrails）

### 端侧 AI（终端开发者独特优势）

- Core ML：模型格式（.mlmodel/.mlpackage）、推理加速（ANE/GPU）
- 模型转换与量化：PyTorch → Core ML 流程、INT8/FP16 量化、蒸馏
- Apple Foundation Models / Apple Intelligence：系统级 AI 能力集成
- 端侧 RAG/搜索：本地 Embedding + 向量检索
- AI 功能端侧架构：流式渲染（打字机效果）、超时/降级/重试策略、离线模式
- 端云协同：端侧小模型 + 云端大模型的路由策略

## 能力八：项目经验与工程素养

> 面试中通过"项目深挖"考察。P6 要求讲清"做了什么、怎么做的、结果如何"；P7 要求体现技术判断力、体系化思考和影响力。

### 项目深度要求

- 至少一个完整的大型 App 项目经验（从 0 到 1 或长期迭代维护）
- 能讲清：业务背景 → 技术挑战 → 方案设计 → 落地细节 → 量化结果
- 性能优化专项：至少一个完整的优化案例（启动/卡顿/内存/包大小/稳定性），有数据支撑
- AI 落地项目（2026 加分/必备）：在 App 中集成 AI 功能的完整经验

### 技术方案能力

- 需求分析与技术拆解：从模糊需求到可执行方案
- 方案对比与选型：能列出 2-3 个方案并给出取舍理由
- 技术文档写作：设计文档（RFC）、方案评审
- 风险识别与预案

### AI 协作与效率（2026 新增）

- AI 辅助编程：Copilot/Cursor/Qoder 等工具的高效使用
- AI 辅助工作流：代码 Review、测试生成、文档生成、Debug
- 判断力：知道 AI 生成代码的局限与风险，能 Review AI 产出

### 技术影响力（P7 要求）

- 技术分享与布道：团队内分享、技术博客
- 方法论沉淀：把个人经验变成团队可复用的工具/规范/流程
- 开源贡献或内部工具建设
- 跨团队协作与技术推动力

## 学习优先级与路线建议

按面试权重与投入产出比排序：

| 优先级 | 能力域 | 理由 | 建议配比 |
|--------|--------|------|----------|
| P0 | 算法与数据结构 | 笔试硬门槛，短期可突破 | 15% |
| P0 | Swift/OC 语言深度 | 面试必考，已有基础需深化到原理层 | 15% |
